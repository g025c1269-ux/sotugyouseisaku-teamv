# ECOSYSTEM — 生態系シミュレーションゲーム

Python・Pygame製の共同卒業制作です。最新mainの生態系・描画を保持し、既存のタイトルとルールベース解説を接続する統合版です。

## ダウンロード

この統合変更はPRでレビューし、**mainへマージした後**に [mainのZIP](https://github.com/g025c1269-ux/sotugyouseisaku-teamv/archive/refs/heads/main.zip) から利用できます。レビュー中は [統合ブランチのZIP](https://github.com/g025c1269-ux/sotugyouseisaku-teamv/archive/refs/heads/integration/explanation-mode.zip) を使用してください。

ZIPを右クリックして「すべて展開」し、以前のダウンロードとは別の新しいフォルダーへ展開してください。ZIP内から直接実行せず、`main.py` と `requirements.txt` がある階層を開きます。Gitは不要です。

## Windowsでの起動（Python 3.12・64bit）

1. [Python公式サイト](https://www.python.org/downloads/windows/)からPython 3.12（64bit）をインストールします。Python Launcher（`py` コマンド）も導入してください。
2. 展開した `main.py` のあるフォルダーをエクスプローラーで開き、アドレスバーに `powershell` と入力してEnterを押します。
3. 次を順に実行します。

```powershell
py -3.12 --version
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

仮想環境の有効化スクリプトは使わないため、PowerShellの実行ポリシーを変更する必要はありません。`py` が見つからない場合はPython Launcherの導入を確認してください。画面がすぐ閉じる場合も、上記PowerShellから起動するとエラーを確認できます。

初回の依存パッケージ導入にはインターネットが必要です。導入後のゲーム起動に外部API・APIキー・Ollamaサーバーは不要です。日本語はシステムフォントを優先し、タイトルと解説には既存の日本語フォント同梱パッケージのフォールバックもあります。

## 観察モードの解説方式

観察モードの設定画面左側で **通常解説（AIなし）**／**AI解説（ローカルLLM）** を選べます。通常解説が初期選択で、Ollamaやネット接続は不要です。

AI解説を選ぶと右側に導入案内が表示され、ローカルOllamaと `qwen3:4b` の有無を確認します。Ollamaを起動し、未導入の場合だけ `ollama pull qwen3:4b` を実行してください。初回ダウンロードにはインターネットが必要です。未起動・モデル不在・確認中の場合も、通常解説へ戻せば開始できます。選んだ方式は新規開始にもロード再開にも適用されます。

シミュレーション中はN/「解説」で選んだ解説を開けます。通常解説は従来の草食全体・肉食全体・選択個体の3吹き出し。AI解説は既存の年間総括（12世代ごと）と手動の個体解説です。AI画面の「観察」から従来の3吹き出しも確認できます。AIの文章・判定・プロンプト・生成タイミングは既存実装を維持しています。

[変更範囲・検証結果・Windows実機の確認手順](docs/explanation_mode.md)。追加のPythonライブラリはありません。Windows実機と本物のモデルでの生成はクラウドから確認していません。

## 利用できる機能

| 機能 | 現在の範囲 |
| --- | --- |
| タイトル | ECOSYSTEM、モード選択、終了 |
| 神様モード | 最新の生態系シミュレーションを起動。新しい介入機能は追加していません |
| ミッション | 「準備中」の仮画面とタイトルへ戻る操作のみ。本格的なミッションは未実装 |
| 生態系 | 最新のNN・生涯学習、遺伝・繁殖・寿命、島・海、季節と気温 |
| 観察ナビ | 草食・肉食全体の平均・分布から短い傾向解説 |
| 個体解説 | 選択個体の短い紹介と、数値・分類・長所・注意点の詳細 |
| 案内役 | 葉っぱの顔アイコンと吹き出し |
| Ollama / Qwen3 4B | 設定で任意に選択。既存の年間総括・個体AI解説を使用。未接続時はルール解説へ代替 |

生態系のNN・強化学習は従来からある個体行動の計算です。通常解説はJSONとPythonの条件分岐で生成します。AI解説を選んだ場合だけローカルOllamaを使い、文章を表示します。

## 操作

タイトルで「神様モード」を選ぶとシミュレーションが始まります。生物はドラッグせず左クリックして離すと選択できます。Spaceで一時停止、2・3キーで拡大すると選びやすくなります。

| 操作 | 動作 |
| --- | --- |
| Space | 一時停止・再開 |
| M / ← / → | 1世代ごとモード、世代の戻し・送り |
| 1 / 2 / 3、マップ上のホイール | ズーム |
| WASD、マップのドラッグ | カメラ移動 |
| F | 選択個体の追跡 |
| V | 食物の表示切替 |
| E | **最新mainの季節エフェクト切替を維持** |
| N | 観察ナビと従来の操作・平均パネルの切替 |
| Tab / 「詳細」 | 選択個体の詳細解説と吹き出しの切替 |
| Esc / ウィンドウを閉じる | ゲーム終了 |

速度は従来の右側パネルの低速・中速・高速ボタン（5・10・15ステップ/秒）で変更します。ナビで隠れている場合は **N** または「閉じる」で従来表示に戻してください。詳細解説はホイールでスクロールできます。ナビを表示してもシミュレーションは自動停止しません。

終了時の結果グラフは実行したフォルダーに保存されます。ミッション仮画面からは「タイトル画面に戻る」で復帰できます。
