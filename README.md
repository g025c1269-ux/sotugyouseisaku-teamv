# sotugyouseisaku-teamv

## ステータス解説版のダウンロード

対象ブランチは **`feature/status-explainer`** です。

**[このブランチのゲーム一式をZIPでダウンロード](https://github.com/g025c1269-ux/sotugyouseisaku-teamv/archive/refs/heads/feature/status-explainer.zip)**

GitHubの「Code → Download ZIP」を使う場合は、先にブランチ選択を `feature/status-explainer` にしてください。`main` のZIPとは別の内容です。古いフォルダへの上書きではなく、新しい場所にZIPを解凍してください。

`docs/status_combinations.zip` は解説一覧CSVだけのファイルです。ゲーム本体ではありません。

## 起動と観察ナビ

1. ZIPを新しいフォルダに解凍し、その中で `python main.py` を起動します。
2. 右側に草食・肉食の群れの傾向と、個体の選択案内が表示されます。
3. 生物をドラッグせず左クリックして離すと、下の吹き出しで個体の特徴を紹介します。白い点が草食、赤い点が肉食です。Spaceで一時停止、2・3キーで拡大すると選びやすくなります。
4. **E** または「閉じる」で従来の操作パネルへ戻り、Eでナビを再表示します。
5. 個体を選択して **Tab** または「詳細」を押すと、以前の数値・LOW/MID/HIGH・長所・短所の詳しい解説を読めます。詳細はホイールでスクロール、Tabまたは「閉じる」で吹き出しへ戻ります。

ナビを開いても自動停止しません。WASD（Dを含む）のカメラ移動、Vの食物表示切替などは従来どおりです。速度スライダーはEで従来パネルへ戻して操作できます。

[観察ナビの仕様・判定ルール](docs/navigator.md) / [最新画面](screenshots/14_navigator_overview.png)

依存パッケージが未導入の場合は、使用するPython環境で次を実行してください。

```bash
python -m pip install numpy matplotlib japanize-matplotlib pygame "setuptools<81"
python main.py
```

## 最新の生態系・描画更新への対応

このブランチは最新mainの島・海・160×160マップ・NN行動選択・寿命の更新（`0cff08c`まで）を取り込み、解説パネルの接続を復元しています。計算・描画のファイルは取り込んだmainと同じ内容を保持しています。

- 現在のNN方式では `hunger_threshold` は行動選択に使われないため、値と評価を残したうえで「現在の方式では未使用」と表示します。長所・短所には含めません。
- 年齢は寿命300ステップとともに表示し、300を超えたステップで死亡することを説明します。
- NN方式の繁殖に必要なエネルギー・年齢10以上・肉食草食比0.3以下と、近隣草食数の抽選条件を説明します。
- 旧ルール方式に切り替えた場合は、旧方式に合った文章へ自動的に切り替わります。
- 海への移動キャンセルと、別枠で遺伝する脳の126パラメータも説明します。脳の重みから行動の成功を断定しません。

22テストで平均・分布に基づく全体傾向、短い個体紹介、吹き出し表示、両方式・両種の全8,748件の詳細解説、境界値、寿命・繁殖条件、計算と乱数への無副作用、実際の選択・表示切替を確認しています。画面確認はSDL offscreenで行い、実デスクトップの手動操作は未検証です。

変更は `feature/status-explainer` にだけpushします。`main` には変更しません。
