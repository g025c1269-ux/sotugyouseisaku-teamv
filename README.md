# ECOSYSTEM — 生態系シミュレーションゲーム

Python・Pygame製の共同卒業制作です。最新mainの生態系・描画と既存のゲーム機能を保持し、任意で使えるOllamaのローカルAIナビを追加しています。

## ダウンロード

**AIナビの確認には [feature/ollama-navigatorのZIP](https://github.com/g025c1269-ux/sotugyouseisaku-teamv/archive/refs/heads/feature/ollama-navigator.zip) を使用してください。** mainには直接反映していません。レビュー・マージ後に [mainのZIP](https://github.com/g025c1269-ux/sotugyouseisaku-teamv/archive/refs/heads/main.zip) からも利用できます。

ZIPを右クリックして「すべて展開」し、以前のダウンロードとは別の新しいフォルダーへ展開してください。ZIP内から直接実行せず、`main.py` と `requirements.txt` がある階層を開きます。Gitは不要です。

## Windowsでの起動（Python 3.12・64bit）

1. [Python公式サイト](https://www.python.org/downloads/windows/)からPython 3.12（64bit）をインストールします。Python Launcher（`py` コマンド）も導入してください。
2. 展開した `main.py` のあるフォルダーをエクスプローラーで開き、アドレスバーに `powershell` と入力してEnterを押します。
3. 次を順に実行します。

```powershell
py -3.12 --version
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

仮想環境の有効化スクリプトは使わないため、PowerShellの実行ポリシーを変更する必要はありません。`py` が見つからない場合はPython Launcherの導入を確認してください。画面がすぐ閉じる場合も、上記PowerShellから起動するとエラーを確認できます。

初回の依存パッケージ導入にはインターネットが必要です。導入後のゲーム起動にAPIキー・Ollamaサーバーは不要です。年末の総括・個体解説の更新時だけローカルのOllamaを使い、停止中でもルール解説とゲームを利用できます。日本語はシステムフォントを優先し、タイトルと解説には既存の日本語フォント同梱パッケージのフォールバックもあります。

## ローカルAIナビ（Ollama / qwen3:4b）

1. WindowsでOllamaを起動し、PowerShellの `ollama list` に `qwen3:4b` があることを確認します。インストール済みならモデルの再取得は不要です。
2. 上記の手順でゲームを起動し、「神様モード」へ進みます。
3. **N** または右上の「解説」→ **AI** を押します。
4. **「年間総括」** で年末の自動レポートを確認します。既存の `SEASON_CYCLE`（現在12世代）で1年です。**M → 右矢印** で1世代ずつ進めると、12世代終了時の総括を確認できます。
5. **「選択個体」** は、マップで生物を選んでから「AI解説を更新」を押します。個体のルール解説・詳細も維持しています。

年間総括は年末に1回だけ自動生成します。前の総括を表示したまま「次の年間レポートを作成中...」と案内し、完成したら更新します。「前の総括」「次の総括」「最新へ」で履歴を見られます。生成が遅くても年ごとの確定データをキューに入れ、個体解説と合わせて1件ずつ処理します。生成待ち中もマップ操作や一時停止を使えます。

年間総括は両種の個体数・平均形質の増減、観測した気温・季節・食料を使う160〜190文字のコメントです。未取得の災害などを作らず、環境と増減の因果は断定しません。途中で全種絶滅・最大世代に達した年は、途中までの総括を残します。巻き戻して同じ年を再訪しても再生成せず、初回到達時の記録を維持します。

各年の年初・年末の値、AIへの入力、回答、エラーは起動したフォルダーの **`reports/annual_*.json`** に保存します。AIが利用できない場合はルールベースの年間総括を表示します。過去の総括は起動中の画面から閲覧でき、終了後はJSONを確認できます。以前の起動の履歴を画面へ読み込む機能はありません。

接続設定は [data/ollama_config.json](data/ollama_config.json)（標準60秒、`think=false`）。年間は出力上限512トークン、個体は256トークン・40〜80文字です。追加のPythonライブラリはありません。

保存された年の入力をWindowsで実モデルへ再送信して確認できます（ファイル名は実際の名前へ置換）。ゲーム内の履歴ファイルは変更しません。

```powershell
.\.venv\Scripts\python.exe verify_ollama.py --annual-report .\reports\annual_実際のファイル名.json --year 1
```

クラウド環境から利用者PCのlocalhostには接続できないため、**実機qwen3:4bの応答品質・生成時間・Windows実画面は未検証**です。[年間総括の仕様・実機チェック](docs/ollama_navigator.md)に確認手順を記載しています。

## 利用できる機能

| 機能 | 現在の範囲 |
| --- | --- |
| タイトル | ECOSYSTEM、モード選択、終了 |
| 神様モード | 最新の生態系シミュレーションを起動。新しい介入機能は追加していません |
| ミッション | 「準備中」の仮画面とタイトルへ戻る操作のみ。本格的なミッションは未実装 |
| 生態系 | 最新のNN・生涯学習、遺伝・繁殖・寿命、島・海、季節と気温 |
| 観察ナビ | 草食・肉食全体の平均・分布から短い傾向解説 |
| 個体解説 | 選択個体の短い紹介と、数値・分類・長所・注意点の詳細 |
| 案内役 | 葉っぱの顔アイコンと吹き出し |
| Ollama / Qwen3 4B | 年末の年間総括・履歴、手動の選択個体解説。非同期生成・単一キュー・ルール代替。実モデルはWindowsで確認 |

生態系のNN・強化学習は従来からある個体行動の計算です。ルール解説はJSONとPythonの条件分岐で生成し、AIは表示文章だけを作ります。AIから生態系のパラメータや行動を変更する接続はありません。

## 操作

タイトルで「神様モード」を選ぶとシミュレーションが始まります。生物はドラッグせず左クリックして離すと選択できます。Spaceで一時停止、2・3キーで拡大すると選びやすくなります。

| 操作 | 動作 |
| --- | --- |
| Space | 一時停止・再開 |
| M / ← / → | 1世代ごとモード、世代の戻し・送り |
| 1 / 2 / 3、マップ上のホイール | ズーム |
| WASD、マップのドラッグ | カメラ移動 |
| F | 選択個体の追跡 |
| V | 食物の表示切替 |
| E | **最新mainの季節エフェクト切替を維持** |
| N | 観察ナビと従来の操作・平均パネルの切替 |
| Tab / 「詳細」 | 選択個体の詳細解説と吹き出しの切替 |
| Esc / ウィンドウを閉じる | ゲーム終了 |

速度は従来の右側パネルの低速・中速・高速ボタン（5・10・15ステップ/秒）で変更します。ナビで隠れている場合は **N** または「閉じる」で従来表示に戻してください。詳細解説はホイールでスクロールできます。ナビを表示してもシミュレーションは自動停止しません。

終了時の結果グラフは実行したフォルダーに保存されます。ミッション仮画面からは「タイトル画面に戻る」で復帰できます。
