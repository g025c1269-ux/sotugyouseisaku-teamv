# リーフの観察メモ

## 画面と操作

`python main.py` を起動すると、既存の右側400pxの領域にナビキャラと3つの吹き出しが表示されます。左側のマップは拡張・縮小・描き換えをしません。

- 上：草食動物全体。生存数、平均値の補足と、群れの短い解説。
- 中：肉食動物全体。同じ基準で独立に集計。
- 下：選択個体の短い紹介。未選択ならクリックを案内。

**N** または上部の「閉じる」で従来の操作・平均パネルへ戻ります。Nで再表示できます。生物を新しく選択したときもナビが開きます。

生物を選択した状態で **Tab** または「詳細」を押すと、これまでの数値・LOW/MID/HIGH・長所・注意点・計算上の説明を表示します。詳細画面はホイールでスクロールし、Tabまたは「閉じる」で3つの吹き出しに戻ります。Nでは従来のパネルへ戻ります。

**Dは引き続きカメラ移動**です。Space、M、世代送り戻し、WASD、F、V、Eの季節エフェクト、マップ上のズーム・ドラッグ、Escは既存の処理を使います。右側の吹き出し表示中は背後の速度ボタンを操作できないため、速度を変える場合はNで従来表示へ戻してください。ナビ表示でシミュレーションは自動停止しません。

## 短い文章の作り方

外部APIは使用しません。`data/navigator_text.json` に短い2〜3文の候補を用意しています。生物や群れの特徴から文章の種類を選び、補給・気温・寿命の注意を必要な場合だけ1文追加します。

草食と肉食では同じ特徴でも言い回しを変えます。文章選びにはSHA-256から求める固定インデックスを使い、PythonやNumPyの乱数を消費しません。同じ特徴なら文章が毎フレームちらつくこともありません。

### 全体解説

死亡個体は集計から除き、種ごとに6遺伝子の平均値とLOW/MID/HIGHの個体数を計算します。閾値は既存の `StatusExplainer` と共通です。

群れの特徴は次の順で判定します。

1. **速度HIGHかつ川LOWの同じ個体が60%以上**：すばやいが川は苦手。
2. **川HIGHかつ山HIGHの同じ個体が60%以上**：川と山に適応。
3. **温度適性・速度・代謝・川・山の5項目すべてMIDの個体が60%以上**：バランス型が多い。
4. その5項目のどれかで **LOWもHIGHも25%以上**：いろいろなタイプがいる群れ。
5. 各能力のLOWまたはHIGHが60%以上：最も割合が大きい特徴。割合が同じ場合は川・山・速度・代謝・温度適性の順。
6. それ以外：一つの特徴に偏っていない群れ。

平均が0.5でもLOWとHIGHに分かれている場合は、バランス型とは呼びません。また「速度が高い個体が多い」と「川が苦手な個体が多い」だけで、同じ個体が両方に当てはまるとは決めつけません。

0匹なら観察できないことを表示し、1匹なら「今は1匹だけの観察」と明示します。過去との比較は行っていないため、「進化してきた」「増えてきた」など時間変化を断定する言い方はしません。

### 個体解説

選択個体の値を同じ閾値で分類し、川と山の組み合わせや速度と川の組み合わせを優先して紹介します。ほかは目立つ得意・苦手、または中間的なタイプを紹介します。

充足率が40%未満なら蓄えへの注意、気温10℃以下かつ `abs(気温 / 40 - 温度適性遺伝子) > 0.35` なら今の寒さによる消耗への注意、年齢が寿命の85%以上なら年齢への注意を追加します。群れでは充足率・気温の注意に該当する個体が60%以上のときだけ追加します。これらは観察用の目安で、新しい行動条件ではありません。

`cold_resistance` の実際の式に合わせ、高いほど寒さに強いという説明にはしません。NN方式で「逃走が最優先」「必ず狩りに成功」とも言いません。`hunger_threshold` は短い傾向解説には使用せず、NNでは未使用であることやルール方式での働きは詳細画面で確認できます。

## ファイル

- `navigator_explainer.py`：読取専用の集計・個体紹介・文章選択。
- `navigator_panel.py`：図形の顔アイコン・吹き出し・3カード・表示切替。
- `data/navigator_text.json`：短文と候補文。
- `main.py`：既存の解説接続で使うクラスを `NavigatorPanel` に変更する2行のみ。
- `status_panel.py` / `status_explainer.py`：従来の詳細解説をそのまま維持。
- `tests/test_navigator.py`：集計・分布・短文・無副作用・レイアウトの検証。

群れの集計はワールド・ステップ・気温・行動方式が変わったら更新します。個体の短い紹介は表示時の最新値を読みます。世代を戻してワールドが置き換わった場合も集計し直します。
