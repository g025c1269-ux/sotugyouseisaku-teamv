# リーフの観察メモ（全体解説のみ）

通常・AIとも、選択個体に対する文章解説はありません。個体向けのタブ、AI更新ボタン、AIリクエスト、短文・総合解説・長所/短所の生成処理は削除しました。

通常ナビは草食全体と肉食全体の2つの吹き出しで、年初と年末の変化を紹介します。AIナビは年間総括だけを表示します。「前の総括」「最新へ」「次の総括」、文章のホイールスクロール、リーフのアイコンと配色は維持しています。更新は両方式とも既存の春夏秋冬1周期（現在12世代）ごとです。

N/「解説」で開閉します。AI画面の「観察」で両種の全体カード、「AI」で年間総括へ戻ります。年末前・生成中は従来どおり前回の文章を保持します。成功/失敗・通常解説への代替、タイムアウト、reportsの履歴と診断ログ、モデル設定、年間AIのプロンプトと入力は変更しません。

個体をクリックするとゲーム本体のステータス表示が使えます。クリックでナビゲーターを自動的に開くことはしません。Tab/「詳細」は[数値詳細](status_explainer.md)を表示し、数値・LOW/MID/HIGH・消費値を確認できます。ここにも個体専用の文章はありません。

Space、M、世代の送り戻し、WASD、Fの追跡、V、E、ズーム、ドラッグ、タイトル・ミッション・介入等の処理は変更していません。速度ボタンを使う場合はN/「閉じる」で元のパネルへ戻ります。

共有の集団集計・分類・全体向け文章は維持しています。集団が1匹の場合の候補文は集団集計でも使われるため残していますが、選択した個体を解説する呼び出しはありません。

削除対象のテストは、全体解説・個体選択・数値確認のテストへ更新しています。実Ollamaの生成とWindows実デスクトップでの操作はクラウドから確認していません。
