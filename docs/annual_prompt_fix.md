## 調査結果と変更

従来の受信検査はJSON・長さ・両種への言及等だけで、文章が「観察結果」か「指示の説明」かを区別していませんでした。そのため、報告された復唱も形式上はAI成功になり得ます。

リポジトリのai_model/ModelfileはFROM qwen3:1.7b。長い役割・口調・考察手順がPython側と重複します。Modelfileは原因仮説を重視し、従来Python側は因果の断定禁止を繰り返すため、重点が異なります。ただし「仮説」と「断定禁止」は両立し、重複だけで今回の原因とは断定できません。APIで明示するsystemと、導入済みモデルのSYSTEM/TEMPLATEの実際の適用状態もこの調査だけでは確定できません。

ユーザーPCの実際のモデル定義は取得していません。Windowsで `ollama show ecosystem-leaf:latest --modelfile` を実行すると確認できます。リポジトリ内のファイルと同一とは仮定せず、Modelfileは変更・再構築していません。

Pythonの年間指示だけを短い5行へ整理しました。数値の観測→ルールに合う仮説→次年の観察点を優先し、不明な原因を無理に補わせません。

受信後は年間回答だけに、出力形式や指示を説明する具体的な言い回しの検出を追加します。検出時はinstruction_echoとして不採用にし、既存の通常解説へ代替。診断ログのsuccess=false / error_kind=instruction_echoと、従来の履歴にリクエスト・不採用回答を残します。自動再試行は増やしません。

「ください」「仮説」「増減」「平均形質」だけでは拒否しません。意味全体を判定するAI検査ではないため、あらゆる言い換えの検出や誤検知ゼロ、回答の事実整合性の完全な検証は保証しません。

通常/個体解説、年1回更新、120秒設定、時間計測・診断ログ、JSON補正、生態系計算・UI・描画は変更していません。
