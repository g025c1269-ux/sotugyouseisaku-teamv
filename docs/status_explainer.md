# 数値ステータスの確認

個体をクリックすると従来のゲーム本体のステータス表示を確認できます。Tabまたは「詳細」で開く画面も、数値・3段階評価専用として維持します。

表示対象は種類、生死、エネルギー/容量、行動数、行動方式、位置、各遺伝子と充足率の数値・LOW/MID/HIGH、基本/温度/移動消費、気温/適温、繁殖最低行動数、NNのパラメータ数などです。値を読むだけで、生態系の計算や乱数を変更しません。

個体の紹介文、組み合わせの総合解説、環境についての文章、長所/短所は生成・表示しません。個体解説のCSV出力も削除しました。

`status_explainer.py` のStatusExplainerは、集団集計と数値画面が共通で使用する分類処理として残します。`data/status_explanations.json` は分類のキー・ラベル・閾値・未使用方式・種/方式名だけを保持します。閾値や分類計算は変更していません。

LOWは下の閾値未満、MIDは下の閾値以上かつ上の閾値未満、HIGHは上の閾値以上です。数字が大きいほど有利という意味ではありません。NN方式では繁殖の重み（hunger_threshold）は未使用と表示します。

ホイールで数値画面をスクロールし、Tab/「閉じる」で全体の観察メモへ戻れます。Nは元のパネルとの切り替えです。選択・追跡・ズーム・介入などのゲーム操作は削除していません。
