# 観察モード：通常解説とAI解説の統合

## 基準と再利用元

- 基準main：`6b5d0253479dcaaaf6586226ce5efea723bff98b`。
- 通常解説ブランチ：`feature/status-explainer` の `7b6eb1b`。実装は既にmainの `navigator_explainer.py` / `status_explainer.py` / `navigator_panel.py` / `status_panel.py` と文章JSONに入っています。main側の最新文章・行動数表記を維持します。
- AIブランチ：`feature/ollama-navigator` の `85ea0a4`。コミット履歴とファイルを確認したところ、AI本体は `7ae7417` のまま残り、接続側のmain.pyとnavigator_panel.pyが通常版へ戻っていました。
- AI本体4ファイルと設定JSONは、AIブランチからバイト単位でそのまま再利用しています。プロンプト・判定・文章・生成頻度を変更していません。

作業ブランチは最新mainから作成した `integration/explanation-mode` です。mainへ直接pushしません。

## 設定画面

既存の中央6項目（x=190〜810、y=104から58px間隔）と下部3ボタン（y=500）の位置・内容を変えず、左の空き領域へラジオ選択を追加しました。AI選択時だけ右の空き領域へ導入案内を表示します。

通常解説が初期選択です。通常解説の開始・ロードではOllamaへの問い合わせ、AIコントローラーの初期化、モデルの読込を必要としません。

AIを選んだときだけ、別のデーモンスレッドで `http://localhost:11434/api/tags` を確認します。標準モデルはqwen3:4bで、既存のAI設定JSONを使います。確認タイムアウトは3秒、同時確認は1件。未起動・モデル不在・応答不良を表示します。「接続を再確認」で再試行でき、通常解説へ戻ればチェック結果に関係なく開始できます。AIを選択したまま未準備・確認中の場合は開始/ロードを実行しません。

案内には指定の導入説明、公式URL、`ollama pull qwen3:4b`、初回のネット接続、PC負荷、導入後のローカル実行を表示します。自動のモデル取得やクラウドAPI呼び出しは行いません。

選択は「開始」と「ロード」の両方で観察モードへ渡します。セーブ形式は変更しません。ロード時にも、その設定画面で今選んだ解説方式を使います。設定画面を開き直したときの初期選択は通常解説です。

## 観察中の表示

- 通常：従来の草食全体・肉食全体・選択個体の3吹き出しと詳細画面を使います。個体未選択時の案内、N・Tab・閉じるの操作も従来どおりです。
- AI：N/「解説」で既存のAI画面を開きます。年間総括と選択個体タブを維持します。「観察」で従来の両種全体・個体の3吹き出しも閲覧できます。
- 年間総括：既存SEASON_CYCLE（12世代）ごとに1回、両種を比較する160〜190文字・5〜6文。確定した年次データを順次処理し、前回文の保持・履歴・JSON保存を維持します。
- 個体AI：個体を選んで更新ボタンを押したときだけ生成。40〜80文字、古い選択個体の結果の破棄を維持します。
- AI生成が失敗した場合は、既存のルール代替文を表示します。

シミュレーション終了時の自動終了、メニュー確認、F5、ロード、季節OFF、速度などは最新mainの動作を維持します。終了時にAIが未完了なら、既存AIのclose処理で未完了状態とルール代替を保存し、終了を待ちません。

既存AIの制約もそのままです。年間レポートは起動中の履歴と `reports/annual_*.json` に保存されますが、既存セーブデータへ年間履歴を追加する変更は行いません。ロードで年途中から始まった年は、観察できた範囲の総括となります。


選択の初期値・マウス/キー操作・導入案内・確認中のUI継続・未起動/モデル不在/時間切れ/不正応答・通常への切替・開始とロードへの引渡しを検証しました。実際のmain.pyで両方式の12世代進行、年間総括、F5、メニュー確認、表示切替、終了を確認しています。テスト内のみステップ数を短縮し、リポジトリの設定値は変更しません。

さらに以下を確認しました。

- 同一の世界・選択個体で、通常ナビの描画ピクセルが元mainと一致。
- 設定画面の中央領域（x=190〜810、全高さ）の描画ピクセルが元mainと一致。通常選択・AI選択の両方で確認。
- 保護対象20ファイルがmainとバイト単位で一致。AIソース5ファイルも再利用元と一致。
- 年間記録を通しても、同じ乱数からの個体・脳の重み・食料・乱数状態が一致。
- HTTP通信は代役サーバー/モックを使用。本物のQwenの生成成功とは区別。

**既存テストの基準との差**：変更前mainの全24テストは19成功・4失敗・1エラーでした。変更後の全56テストは51成功・同じ4失敗・1エラーで、新たな失敗はありません。対象は古いタイトル/仮ミッションの遷移を想定した1件、起動時にナビが開くと想定した3件、旧「年齢」表記を想定した1件です。今回の厳密な変更範囲に合わせ、これらの既存テストや対象外のゲーム機能は書き換えていません。全テスト成功とは報告しません。
